💡 Setup Guide & Best Practices

1. Before Syncing (Avoid Metadata Conflicts)

Ensure that "Automatically add to collection" is disabled in your Jellyfin library settings (under Dashboard → Libraries → [your movie library] → Metadata settings) to prevent conflicts with TMDB auto-collections.

2. Display Settings (Group Movies into Collections)

To group member movies under their collection poster in the main movie library view, enable "Group movies into collections" under Dashboard → Libraries → Display.

3. Folder Structure & Naming Conventions

tinyMediaManager manages movie sets either in a dedicated set folder (recommended: <SetFolder>/<SetName>/<SetName>.nfo) or directly in movie folders.

  • Set Subfolder: .../_sets/Avatar Collection/Avatar Collection.nfo
  • Flat File: .../_sets/Avatar Collection.nfo
  • collection.nfo: .../_sets/Avatar Collection/collection.nfo

4. Movie Folder Artwork Fallback

If a movie set has no dedicated folder in the Set Data Folder (or if you don't use a central set folder), enabling the fallback option allows the plugin to search the member movies' folders for movieset-poster.jpg, movieset-fanart.jpg, etc.
