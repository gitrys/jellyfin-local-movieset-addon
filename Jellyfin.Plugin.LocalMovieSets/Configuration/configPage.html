🛡️ Safety & Cleanup

When enabled, the plugin checks if all configured movie library folders are online and not empty before syncing. If a folder goes offline or becomes empty (e.g. network share drops), the sync is aborted to prevent collections from losing their members.
When enabled, automatically triggers a collection sync 30 seconds after movies are added, updated, or scanned in your library.
Remove Jellyfin collections that no longer have any movies with a matching <set> tag. By default, collections with a TMDB or IMDb provider ID are kept as a safety guard. Note: when this is disabled and a set is renamed in your NFOs, the old collection is left untouched — movies may then appear in both the old and the new collection until you remove the old one manually (or enable this option).
When enabled, orphaned collections are deleted even if they have a TMDB or IMDb provider ID. Use this if your set NFOs contain <tmdbid> tags and you want full automatic cleanup.
When enabled, artwork from the TMM set folder is re-copied on every sync, replacing any existing images on the collection. When disabled, only collections with no artwork are updated.
When enabled, the plugin searches for set artwork (e.g. movieset-poster.jpg, movieset-fanart.jpg) directly inside member movie folders if no dedicated set data folder is configured or if no image was found there.

💡 Setup Guide & Best Practices

1. Before Syncing (Avoid Metadata Conflicts)

Ensure that "Automatically add to collection" is disabled in your Jellyfin library settings (under Dashboard → Libraries → [your movie library] → Metadata settings) to prevent conflicts with TMDB auto-collections.

2. Display Settings (Group Movies into Collections)

To group member movies under their collection poster in the main movie library view, enable "Group movies into collections" under Dashboard → Libraries → Display.

3. Folder Structure & Naming Conventions

Each set needs its own folder inside the Movie Set Data Folder. The NFO file lives in that folder.

  • Set Subfolder: .../_sets/Avatar Collection/Avatar Collection.nfo
  • collection.nfo: .../_sets/Avatar Collection/collection.nfo

4. Movie Folder Artwork Fallback

If a movie set has no dedicated folder in the Set Data Folder (or if you don't use a central set folder), enabling the fallback option allows the plugin to search the member movies' folders for movieset-poster.jpg, movieset-fanart.jpg, etc.
